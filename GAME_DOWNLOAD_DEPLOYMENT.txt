🔧 INTEGRATION WITH CHECKOUT
═══════════════════════════════════════════════════════════════════════════════

After successful payment, automatically grant download access:

```php
// In CartController.php or OrderController.php (after order created)

public function completePayment($order_id, $user_id) {
    // ... process payment ...
    
    // Get all items in order
    $items = $this->db->query(
        "SELECT DISTINCT product_id FROM order_items WHERE order_id = ?"
    )->fetch_all(MYSQLI_ASSOC);
    
    // Grant download access for each product
    foreach ($items as $item) {
        $this->db->query("INSERT INTO user_game_downloads (
            user_id, product_id, order_id, game_download_id, is_active
        ) SELECT 
            ?, ?, ?, gd.id, 1
        FROM game_downloads gd
        WHERE gd.product_id = ? AND gd.is_active = 1
        LIMIT 1");
    }
    
    // Send confirmation email with download link
    // ... send email ...
}
```
