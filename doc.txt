SƠ ĐỒ LIÊN KẾT HIỆN TẠI (LUỒNG CHÍNH)
-------------------------------------------------------------
PUBLIC ENTRY
public/index.php
	├─ include views/partials/header.php
	│    └─ include views/partials/header-layout.php
	├─ load views/client/index.php (home)
	└─ include views/partials/footer.php
			 └─ include views/partials/footer-layout.php

CLIENT PAGES (direct view)
views/client/steam-games.php
	├─ require config/config.php + config/database.php
	├─ query categories/products (Database)
	├─ include SVG icons (public/assets/svg/icons.svg)
	├─ include header/footer partials
	└─ load CSS/JS assets (public/assets/css/*.css, js/*.js)

views/client/product-detail.php
	├─ query product + category
	└─ include components (banner/game-hot/guide...) + partials

ADMIN FLOW
views/admin/*.php
	├─ session check (admin)
	├─ include views/admin/sidebar.php
	├─ render table/form
	└─ gọi JS admin (public/assets/js/admin-*.js)

Admin JS → Controllers
public/assets/js/admin-products.js
	└─ fetch app/Controllers/AdminProductController.php (create/update/delete)

public/assets/js/admin-hot.js
	└─ fetch app/Controllers/AdminProductController.php (toggleHot)

public/assets/js/admin-categories.js
	└─ fetch app/Controllers/AdminCategoryController.php (create/update/delete)

Controllers → Database
app/Controllers/*
	└─ dùng config/database.php (PDO wrapper) để query

Database Layer
config/database.php
	└─ PDO connect → MySQL

Schema Source
database/migration.sql + database/add-cart-tables.sql + database/steamweb-optimizations.sql
